\f0\fs24 \cf0 # Missingness simulation\
\
This folder contains the missingness simulation pipeline developed for the HDD Hackathon trajectory analysis.\
\
The underlying synthetic recovery trajectories were generated by another team member and imported from:\
\
`outputs/df.csv`\
\
This workflow adds realistic wearable-device missingness patterns to the simulated trajectories.\
\
## Contents\
\
- `missingness.R`\
  - R script for adding realistic missingness to the simulated trajectories\
\
- `trajectory_missingness_plot.png`\
  - Visualisation of complete and observed trajectories\
\
- `df_missing_final.rds`\
  - Final dataset containing simulated missingness\
\
## Missingness mechanisms\
\
The simulation includes several realistic missingness mechanisms commonly observed in wearable-device studies:\
\
1. Technical failure (MCAR)\
   - Random isolated missing days independent of activity\
\
2. Device non-wear\
   - Increased missingness during weekends and low-activity days\
\
3. Compliance decay\
   - Increasing probability of missingness over time\
\
4. Behavioural dropout (MNAR)\
   - Longer periods of missingness among individuals with persistently low activity levels\
\
## Notes\
\
Dashed lines in the trajectory plot represent the underlying complete trajectories, while solid lines represent observed trajectories after missingness was introduced.\
\
